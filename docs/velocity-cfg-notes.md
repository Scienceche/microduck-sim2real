## 二、域随机化（DR）全表 —— "模仿实机的什么不确定性"

| 开关（行） | 范围 | 模仿的实机问题 |
|---|---|---|
| COM_RANDOMIZATION（31/57） | ±3mm 起，课程到 ±15mm | 整机质心装偏。**±30mm 版被 2026-07 审计否了**：超出支撑多边形（脚跟在踝后仅 20mm），后向平衡直接训不出来 |
| HEAD_COM_RANDOMIZATION（32/65） | ±3mm → ±10mm | 头部组件（脖子/头壳）质心偏，头是大杠杆 |

| MASS_INERTIA（35/73） | ±5% | 质量与惯量同时缩放（物理一致，质心不动） |
| JOINT_FRICTION（36/76） | ±10% | 关节摩擦预算，走 BAM 专用通道（MuJoCo 原生 dof_frictionloss 在 BAM 下是零） |
| ARMATURE（38/78） | ±10% | 电机转子折算惯量 |
| VELOCITY_PUSHES（39/79–83） | ±0.3 m/s，每 3–6s | 被踢一脚。**±0.5 版被否**：比最大步速(0.4)还大的持续踢，训出"永久紧张步态" |
| IMU_ORIENTATION（40/84） | 随机轴 ≤6° | IMU 焊歪。注意是零中心的随机轴——只训"歪的容忍度"，真实板子的系统性 ~5° 俯仰偏置在 runtime 源头校正，不在这 |
| ENCODER_BIAS（41/85） | ±0.86° 每关节 | 编码器装偏。actor 看到"带偏置的关节角"，critic 看真值（特权） |

## 三、粗糙地形（125–190 行）

- 鸭子只能抬脚 1–2cm → 台阶封顶 1.5cm（默认 10cm）；随机碎石高度 1cm；坡度 1.7°–5.7°。
- 141–143：**倒金字塔台阶地形被删**——它把出生点设到坑底，机器人会穿地掉下去。
- 145–147：网格宽度的算术：0.12m 网格在 8m 地形上会生成 26 万个盒体 → 显存爆；0.45m → 1.7 万个，且 0.45×17=7.65 不整除 8.0（故意的，避免接缝对齐问题）。
- 172–190：`_soften_terrain_contacts`——盒子地形硬边会打出 NaN 冲量，把接触弹簧时间常数加倍（0.02→0.04s）压掉。
- 770/776–777（rough 分支）：接触上限 nconmax 35→200（摔倒时多肢体同时触地会静默丢接触→NaN）；求解器迭代 10→30。

## 五、观测构成（540–643 行）——actor 61 维 / critic 76 维的来历

**actor（策略可见，61 维）**：`base_ang_vel(3) + projected_gravity(3) + joint_pos(14) + joint_vel(14) + 上一步动作(14) + twist命令(3) + head命令(4) + body命令(6)` = 61 ✓

关键操作及理由：

| 行 | 操作 | 为什么 |
|---|---|---|
| 540 | **删 actor 的 base_lin_vel** | 实机 IMU 测不了真实线速度——sim2real 铁律：**策略不许看部署时没有的东西** |
| 544–545 | 双双删 height_scan | 小鸭没有地形扫描传感器 |
| 548 | critic 加回 base_lin_vel | critic 只在训练时用（价值估计），看真值没问题——这叫**特权信息**，critic 76 维比 actor 多的 15 维就是这些（线速度+足部接触力/足高/腾空时长，逐维对表 Day 5 做） |
| 572–578 | IMU 延迟 lag 0–1 | 原来是 3（60ms）——实机 IMU 链路快（±20ms），2026-07 审计改的 |
| 595–598 | 观测噪声大降 | ang_vel 0.2→0.03、joint_pos 0.05→0.001 等（信真实传感器标定） |
| 586–592 | critic 足部项换 _safe 函数 | 2026-08-21 事故：传感器读数 NaN 而状态干净，一个 NaN 毁掉整次训练 |
| 619–621 | joint_vel 固定 lag=1 | Dynamixel 固件的速度是位置滑动平均，策略读到的是上一步的 |
| 628 | 排除 passive_* 关节 | 16 关节里 2 个是下巴连杆被动关节——观测维=动作维=14 的原因 |
| 638–641 | 编码器偏置只给 actor | 真机编码器带偏，critic 看真值 |

## 六、命令系统（645–709 行）

- **twist**（线速度 ±0.4/±0.3 m/s，角速度 ±1.0 rad/s）：固定范围无课程；2% 环境从零速起步（课程拉到 50%）；10% 环境专属"原地转身"桶（lin=0, |ang|≥0.4）。
- **head_pose**（4 维，相对 HOME 的增量）：初始极小（±0.05 等）保输入神经元活着，课程分 5 档放到机械极限（pitch ±1.10 / yaw ±1.40 / roll ±0.31，各留 10% 安全余量）。
- **body_pose**（6 维 x/y/z/roll/pitch/yaw）：vel 环只占位。

## 九、这个文件浓缩的四次"史诗"（读注释=读事故史）

1. **2026-07 大审计**：CoM ±30mm 超支撑多边形、推踢 ±0.5 太猛、IMU 延迟 60ms 不真实、upright 太便宜——一次系统性"仿真比实机难反而学坏"的纠偏。
2. **2026-08-20 头下垂**：错误修法（收紧 std）让策略放弃行走——奖励设计的第一课：**只罚可逃脱的误差，不罚不可避免的物理**。
3. **2026-08-21 NaN 崩溃**：critic 传感器观测一个 NaN 毁全局——所以有 `_safe` 系列和 `nan_state` 终止。
4. **run5 系列（中文注释）**：你自己 10 月的调参线——action_rate -1.0→-0.5、站立占比 30%→50%，注释风格已经和上游的"证据链注释"合流。
